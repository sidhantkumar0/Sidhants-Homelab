# Helpful Links

Documentation and resources I used while building this homelab.

## Kubernetes / K3s
- [K3s Documentation](https://docs.k3s.io/) — official docs: installation, configuration, networking
- [K3s GitHub](https://github.com/k3s-io/k3s) — releases and issue tracking
- [Kubernetes Documentation](https://kubernetes.io/docs/) — core concepts (pods, deployments, services)

## Monitoring
- [kube-prometheus-stack (Helm chart)](https://github.com/prometheus-community/helm-charts/tree/main/charts/kube-prometheus-stack) — Prometheus + Grafana for Kubernetes
- [Prometheus Documentation](https://prometheus.io/docs/introduction/overview/) — metrics and querying (PromQL)
- [Grafana Documentation](https://grafana.com/docs/grafana/latest/) — dashboards and visualization

## Hardware / OS
- [Raspberry Pi Documentation](https://www.raspberrypi.com/documentation/) — Pi OS, hardware specs
